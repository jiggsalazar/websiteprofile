Jigg Salazar Static Website

This folder is a static copy of the WordPress website. You can use it without logging in to WordPress.

How to open:
1. Double-click start-site.bat
2. Your browser should open http://127.0.0.1:8765/

Pages included:
- Home: index.html
- About: about\index.html
- Portfolio: portfolio\index.html
- Contact: contact\index.html

Notes:
- This is a static website, so WordPress admin, plugins, database editing, and backend form handling are not included.
- Images, CSS, and JavaScript needed by the exported pages are saved in the assets folder.
